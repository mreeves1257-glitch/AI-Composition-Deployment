# Classical-only genre pipeline branch

This branch adds an isolated **universal recognition boundary** and **strict execution handoff**. Only Classical is enabled. Nothing is installed into the deployed composer.

Pipeline: selection -> indexed genre profile -> existing interpreter callable -> validated musical plan -> existing composer callable -> existing MIDI/audio pipeline.

The existing interpreter and composer runtime are bundled inside the connected deployment archive; their callable signatures must be verified before integration. The adapter deliberately fails closed rather than composing generic music.

This is a connection scaffold, **not a finished orchestra or proof of original songs**. A complete Classical trial must verify independent note events/stems and distinguish multiple generated pieces.
