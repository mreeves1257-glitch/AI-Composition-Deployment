# Genre Contract v3 Research Workspace

This workspace is intentionally separate from the live Composer.

## Why it exists
The current 55 genre profiles provide a useful semantic baseline, but they do not yet contain enough executable detail for original composition. Genre Contract v3 expands each genre into an evidence-backed musical construction specification.

## Core rule
Do not replace the current registry blindly. Compare every field against external evidence and keep whichever definition is stronger.

## Percentage model
Population mass, presence, activity, musical agency, foreground-window share, and spatial footprint are separate concepts. A large string section may carry more physical mass while a single flute can still receive a clear foreground window.

## Safe integration sequence
Genre/profile -> reasoning -> genre-specific composition/harmony -> population realization -> instrument separation -> sound/resource resolution -> spatial realization -> shared 3D mixer.

## Runtime safety
Nothing in this folder is live runtime authority. The current registry remains untouched until a genre passes research, structural validation, and listening review.
